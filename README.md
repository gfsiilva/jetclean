# JetClean - Estética Automotiva

O **JetClean** é uma landing page moderna desenvolvida para serviços de estética automotiva, focada em alta performance, conversão e uma experiência do usuário (UX) de alto nível.



## Design & Inspiração

O projeto nasceu de um planejamento visual detalhado que pode ser conferido através do protótipo interativo:

 **[Acesse o Protótipo no Figma](https://www.figma.com/proto/61Izw9i2DpbN0wKrd195Lr/JetClean?node-id=32-328&t=zfPSwevK7CvgKx4B-1)**



## Sobre o Processo Criativo

* **Do Figma à Realidade:** O design inicial no Figma serviu como o alicerce e a estrutura principal. No entanto, durante o desenvolvimento, percebi oportunidades de tornar a interface mais viva e dinâmica.
* **Evolução Constante:** O que começou como uma reprodução tornou-se **inspiração para algo melhor**. Adicionei elementos interativos que não estavam no plano original, como animações inteligentes e ajustes estratégicos na seção de localização.
* **Adaptações:** Novas ideias surgiram durante a codificação — como o refinamento de sombras, tipografia e o espaçamento dos cards de serviços — elevando o nível visual do projeto final além do que foi planejado inicialmente.



## Tecnologias Utilizadas

O projeto foi construído com o que há de mais moderno no ecossistema Web atual:

* **React** (Biblioteca principal para interfaces)
* **Vite** (Build tool de alta performance)
* **Tailwind CSS** (Estilização utilitária e responsividade)
* **React Icons** (Biblioteca de ícones vetoriais)
* **Node.js** (Ambiente de desenvolvimento)



## Destaques do Projeto

* **Botão de WhatsApp Inteligente:** Desenvolvido com animações customizadas via `tailwind.config.js` (efeitos de pulsar e bounce a cada 5s) para atrair a atenção do usuário de forma orgânica.
* **Design Responsivo:** Interface totalmente adaptada para smartphones, tablets e desktops.
* **Seção de Localização:** Integrada de forma limpa para facilitar o trajeto do cliente até o estabelecimento.
* **Performance Otimizada:** Graças ao uso do Vite e componentes React bem estruturados.
